# Gabu — Personal Brand Website

Real estate personal brand marketing site for Victor (Gabu).

## Tech Stack

- HTML, CSS, vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com/) (via npm)
- No framework

## Quick Start

```bash
# Install dependencies
npm install

# Build CSS
npm run build

# During development: watch for changes
npm run watch
```

Then open `index.html` in a browser or use a local server.

## Project Structure

| Path | Purpose |
|------|---------|
| `index.html` | Homepage |
| `portfolio.html` | Portfolio / Our Work |
| `services.html` | Services |
| `style.css` | Tailwind source + custom styles |
| `dist/output.css` | Built CSS (generated) |
| `js/animations.js` | Scroll reveal, carousel, FAQ, etc. |
| `images/` | Assets |
